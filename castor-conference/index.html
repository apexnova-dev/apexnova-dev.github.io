Castor Conference App

A progressive web app for conferences run by Pennsylvania EMS councils: digital badges, staff scanner, geofenced self check-in with rolling room QR tokens (Supabase Edge Function), schedule and materials, speakers, vendors, CEUs, PDF certificates, and admin reporting with CSV exports suited to state continuing-education workflows.

What it is

Castor targets real event day: multi-track schedules, session materials in Supabase Storage, mandatory evaluations before certificates, announcements, registration CSV import, and admin exports (including one-row-per-attendee data for state bulk upload). Auth, database, and edge logic live in Supabase.

Stack in the repo: React 18, TypeScript, Vite, Tailwind CSS, Supabase (auth, Postgres, Edge Functions) and PWA tooling. This GitHub Pages URL is static gallery copy; a runnable instance uses its own Supabase project, environment, migrations, and hosting (see the README and docs/GETTING_STARTED.md in the repository).

Ownership: Castor is independent software maintained in the linked repository — not the property of any council unless that council adopts and operates its own deployment under its authority.

On-site

Badges, staff scanner, self check-in (geofence + room QR), schedule, bookmarks, and session materials.

Credits

CEU tracking, evaluations before certificates, PDF certificates with certification numbers, and admin state CE CSV exports for Pennsylvania-style bulk upload.

Back office

Admin dashboard, registrations (including CSV import), users, vendors, speaker profiles, announcements, and Room QR setup.

Where things stand

Development in the open includes SQL migrations under supabase/migrations, the validate-room-checkin Edge Function, storage for document vault, and docs for pre-launch checks. Public demo URLs should be read as staging until a deployment is explicitly promoted for a live conference.

Not the hosted app. This URL is descriptive only. Building, configuring, and deploying the PWA is documented in the repository README and deployment guides.
