Castor Conference App

A progressive web app for conferences run by Pennsylvania EMS councils: digital badges, staff scanner, geofenced self check-in with rolling room QR tokens (Supabase Edge Function), schedule and materials, speakers, vendors, CEUs, PDF certificates, and admin reporting with CSV exports suited to state continuing-education workflows.

What it is

Castor targets real event day: multi-track schedules, session materials in Supabase Storage, mandatory evaluations before certificates, announcements, registration CSV import, and admin exports (including one-row-per-attendee data for state bulk upload). Auth, database, and edge logic live in Supabase.

Stack in the repo: React 18, TypeScript, Vite, Tailwind CSS, Supabase (auth, Postgres, Edge Functions) and PWA tooling. This GitHub Pages URL is only a static pitch; any live app needs your own Supabase project, env vars, migrations, and host (see the README and docs/GETTING_STARTED.md in the repository).

On-site

Badges, staff scanner, self check-in (geofence + room QR), schedule, bookmarks, and session materials.

Credits

CEU tracking, evaluations before certificates, PDF certificates, and admin CSV exports shaped for Pennsylvania EMS council and state CE reporting needs.

Back office

Admin dashboard, registrations (including CSV import), users, vendors, speaker profiles, announcements, and Room QR setup.

Where things stand

Development in the open includes SQL migrations under supabase/migrations, the validate-room-checkin Edge Function, storage for document vault, and docs for pre-launch checks. Treat any shared URL as staging until you promote it for a real conference.

Not the hosted app. This URL only describes Castor. To run or deploy the PWA, clone the repo, configure Supabase, and follow the project README and deployment docs.
