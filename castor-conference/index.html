Castor

A progressive web app for conferences, trainings, and multi-track events: digital badges, QR check-in, GPS-validated attendance, dynamic session tokens, credit tracking, PDF certificates, and admin reporting with CSV exports.

What it is

Castor handles the full event lifecycle: attendee registration, digital credentials, location-aware check-in, session access control, mandatory evaluations, and automated certificates. Organizers get real-time dashboards and bulk data exports.

Stack: React 18, TypeScript, Vite, Tailwind CSS, Supabase (auth, Postgres, Edge Functions) and PWA tooling. Built mobile-first with offline capability — it works in crowded venues and remote training sites where connectivity is spotty.

Built for: conferences, professional trainings, continuing education programs, corporate events, and trade shows.

On-site

Digital badges, staff scanner, self check-in with geofencing and room QR, schedule, bookmarks, and session materials.

Credentials

Credit-hour tracking, evaluations before certificates, PDF certificates with certification numbers, and admin CSV exports for bulk reporting.

Back office

Admin dashboard, registrations, user management, vendors, speaker profiles, announcements, and room QR configuration.

Where things stand

Castor is in active development after field-testing at real events. The repo includes SQL migrations, a Supabase Edge Function for room validation, storage for document vaults, and deployment guides. Public demo URLs are staging environments.

Origin: Originally developed for Pennsylvania EMS council continuing-education conferences, refined in a demanding, compliance-heavy environment.

Not the hosted app. This URL is descriptive only. Building, configuring, and deploying the PWA is documented in the repository README and deployment guides.
