Void.md

A single-page Kanban board designed to work in constrained environments — including MDTM — without losing clarity or flow.

What it is

Void.md is a flagship Apexnova product: a lightweight board you can ship as static GitHub Pages, open locally, or embed in a workflow where heavier tools are not an option.

This path (/void-md/) is the short preproduction narrative on this site. The live application is published separately at apexnova-dev.github.io/Void.md from its own repository.

Portable

Runs where a browser runs — no install story required for many use cases.

Focused

One surface for columns and cards, tuned for clarity over feature sprawl.

Open

Source on GitHub so you can fork, theme, or extend without a black box.

Try it

Open the deployed app, read the repo, or return to the hub. Changes to the Kanban itself ship from the Void.md repository, not from this pitch page.
