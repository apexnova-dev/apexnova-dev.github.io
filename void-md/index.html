Flagship · local-first

Void.md

Visual Kanban. Plaintext soul. No cloud. Your Markdown files are the database: open the app, grant a folder via the File System Access API, and work offline-first — with an optional static deploy on GitHub Pages when you want it.

What it is

Void.md ships as a standalone web app (including a single void.html workflow): boards, filters, archives, rich notes (Tiptap) with Markdown fallback, and docs for AI-friendly column syntax. There is no hosted backend — storage is the files you choose, Git-friendly and suitable for air-gapped use.

This path (/void-md/) is a short preproduction narrative on this hub. The canonical deploy from the Void.md repo lives at apexnova-dev.github.io/Void.md (see docs/github-pages.md there for branch build options).

Plaintext

kanban.md and archives — tasks stay in files you own, diff, and back up like any repo.

Browser-native

File System Access API for read/write to disk; optional telemetry; works when “no account” is a requirement.

Documented

Architecture, AI workflow, and column-ID rules so assistants and teams do not corrupt the board format.

Try it

Use the live Pages build for a zero-install demo, clone for local void.html + folder workflow, or browse docs in the repo. Product changes ship from Void.md on GitHub, not from this pitch page.
